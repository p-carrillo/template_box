# DEC-000: Decision title

- **Status:** Proposed | Accepted | Rejected | Superseded
- **Date:** YYYY-MM-DD
- **Owner:** Pending

## Context

What situation or need requires this decision?

## Decision

What is being decided? If it has not been accepted yet, make clear that it is a proposal.

## Alternatives considered

- **Alternative:** description and reasons for considering it.

## Consequences

- Expected effects, costs, risks, and trade-offs.

## Review

What evidence or change would justify revisiting this decision?
